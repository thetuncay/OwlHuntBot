OwlHunt — Bağlı Rol

Discord Linked Roles · Bağlantı doğrulama sayfası

Bu sayfa Discord Developer Portal’daki Linked Roles Verification URL adresidir. Sunucundaki bağlı rolü almak için OwlHunt oyun hesabını Discord profiline bağlaman gerekir.

Ne olacak?

  1. Discord ile giriş yapacaksın (identify + role_connections.write izni).
  2. OwlHunt, oyun istatistiklerini (seviye, av, güç) Discord’a gönderir.
  3. Sunucu yöneticisinin tanımladığı kriterleri karşılıyorsan rol otomatik verilir.

Paylaşılan veriler

  • level — oyuncu seviyesi
  • hunts — toplam av sayısı
  • power — güç skoru
  • registered — oyuna kayıtlı mı (1/0)

Şifre veya e-posta istenmez. Detay: Gizlilik Politikası.

Discord ile bağlan

Henüz OwlHunt’a kayıtlı değilsen önce Discord’da botu kullanıp kayıt ol. Bağlantı yine kurulur; istatistikler 0 görünür.
