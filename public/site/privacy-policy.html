Privacy Policy

Gizlilik Politikası

Last updated / Son güncelleme: 16 June 2026

OwlHunt collects Discord user IDs and gameplay statistics to run the game. We do not sell your data. You can request deletion via our support server.

1. Who we are

OwlHunt is a Discord bot and website operated at owlhunt.thetuncay.com. Contact: support server.

2. Data we collect

Discord bot (gameplay)

  • Discord user ID — primary account key
  • Username / display name — registration and leaderboard display
  • Guild ID and name — registration record, channel restrictions
  • Game data — level, XP, coins, hunts, inventory, owls, PvP, market history
  • Usage telemetry — optional performance and abuse-detection metrics

Website (Discord OAuth login)

  • When you log in: user ID, username, avatar URL
  • Optional: email if the OAuth scope includes it
  • Session cookie — keeps you signed in (up to 30 days)
  • We never ask for a password

Linked Roles (Bağlı Roller)

If you connect your account for a Linked Role, you authorize OAuth scopes identify and role_connections.write. We then send gameplay metadata to Discord (level, hunt count, power score, registered status) via Discord’s Role Connections API. No password or email is transmitted in this flow. Start URL: /verify-user.

3. How we use data

  • Run game mechanics (global economy, leaderboard, market)
  • Prevent cheating and abuse
  • Show your profile and public leaderboard on the website
  • Respond to support requests

We do not sell data or use it for third-party advertising profiles.

4. Retention

Game data is kept while your account is active. Long-inactive accounts may be archived per storage policy. Audit logs are retained for a limited time.

5. Cookies

Only essential session cookies for web login and OAuth state. No analytics or ad cookies.

6. Third parties

  • Discord API — bot, OAuth, Linked Roles
  • Hosting — server infrastructure (PostgreSQL, Redis)
  • AI providers — only if you use the optional w soru command (question text only)

7. Public information

The leaderboard page shows top global rankings. Your profile page (when logged in) shows your stats. The /lb command in Discord shows similar data.

8. Your rights

You may request access, correction, or deletion of your data by contacting the support server. Discord’s own privacy settings also apply.

9. Security

Database access is restricted. Sessions are signed. Report security issues to the support server.

10. Changes

This policy may be updated. The current version is always published on this page.
